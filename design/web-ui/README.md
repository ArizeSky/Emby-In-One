## 与代码的关系

- **目标文件**：`public/web/web.html`（390 行，Vue 3 全局构建 + Tailwind，无构建步骤）
- **改造约束**：不动 `app.js` 数据流（api/fetch 结构、路由、AbortController 生命周期）与 `player-libmedia.js` 播放内核；表现层 JS 增量约 300-350 行（Hero 轮播、自动隐藏、快捷键、Toast、无限滚动、最近搜索、季分段、异常态挂接），逐项独立可回滚——完整清单见 02 §15.1
- **数据可行性**：预览用到的评分/年份/流派/分级字段均已核实**零额外上游调用**（02 §13.3）；海报卡所需 `CommunityRating / ProductionYear / UserData` 数据层已存在
- **零新增依赖**：沿用现有 Tailwind + lucide 体系

## 原全量设计路线（历史估算约 5.5 人日）

以下为原设计全量路线；V1.4.4-rc2 的执行顺序与范围请使用 05 §9，不沿用该估算承诺。

P1 地基（令牌 / z-index / focus-visible，0.5d）→ P2 核心组件（0.5d）→ P3 页面含异常态与第一梯队三项（1.75d）→ P4 播放器含异常态、状态机、自动连播与外部播放器直链（2.25d）→ P5 增强（0.5d）。
每阶段独立可发布、可回滚。详见 `02-design-notes.md` §10。
